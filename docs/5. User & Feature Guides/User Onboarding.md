# User Onboarding

Welcome to the user onboarding guide. This document walks visitors and administrators through their first interactions with the Dharmandala Sandhyakala website.

---

## 1. Visitor Onboarding

When a new user visits the platform, they undergo the following onboarding flows:

### A. Exploring the Home Portal
*   **Hero Sections & Countdowns**: Dynamic animations showcase the primary campaign/event themes, complete with real-time countdown modules.
*   **Cabinet Roster**: Visually stunning OSIS and MPK structural diagrams. Users can click on specific boards, divisions, or sections to review team members, Click instagram links, or toggle long quotes.

### B. Accessing Program Kerja & Prestasi Details
*   **Proker Listing**: Program kerjas are grouped cleanly by department. Clicking on a dynamic proker directs users to a beautiful detail portal outlining accomplishments, dates, and media.
*   **Prestasi Sliders**: Accomplishments load via responsive, touch-friendly carousel cards, showing student achievements with direct slider dot controls.

---

## 2. Administrator Onboarding

For school representatives or developers gaining access to the backend systems:

### A. Logging in to the CMS
1.  Navigate to `/login` or `/thamnet` (which handles authentication redirecting).
2.  Provide your username and password credentials seeded or added by another Superadmin.
3.  Once authorized, you will be redirected to the secure `/dashboard` panel.

### B. Board Roles Assignment
Your user profile dictates which sections of the dashboard you are allowed to manipulate:
*   **Superadmins**: Can view and manage the global administrators roster, create and delete administrative users, edit passwords, and assign groups.
*   **Akademis**: Have restricted access specifically to the **Thanos Challenge Board** and student **Prestasi** rosters.
*   **Media**: Gain editing privileges for dynamic multimedia feeds, homepage showcase cards, and blog posts.
